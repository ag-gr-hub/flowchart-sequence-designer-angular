@flowchart-sequence-designer/angular

Angular wrapper for the flowchart & sequence diagram editor. Standalone components with OnPush change detection and NgZone-optimized React bridge.

GitHub → npm →

Install

npm install @flowchart-sequence-designer/angular flowchart-sequence-designer react react-dom
Note: React is a peer dependency — the Angular wrapper renders React components internally via a lightweight bridge.

Quick Start

import { FsdDiagramComponent } from '@flowchart-sequence-designer/angular';

@Component({
  standalone: true,
  imports: [FsdDiagramComponent],
  template: `<fsd-diagram [height]="600" (modelChange)="onModelChange($event)" />`
})
export class MyComponent {
  onModelChange(model: DiagramModel) {
    console.log('Model updated:', model);
  }
}

Model Factories

Helper functions that return pre-built DiagramModel instances for quick prototyping.

import {
  presetFlowchartModel,
  presetSequenceModel,
  emptyModel
} from '@flowchart-sequence-designer/angular';

presetFlowchartModel('flowchart')  // 6-node order flow
presetFlowchartModel('question')   // question/answer router
presetFlowchartModel('journey')    // milestone steps
presetSequenceModel()              // 3-actor login handshake
emptyModel('flowchart')            // blank diagram

Architecture

  • Components use OnPush change detection for optimal performance
  • React renders run outside NgZone — avoids unnecessary change detection cycles
  • Only explicit outputs (modelChange, exportEvent) trigger change detection via zone.run()
  • Dynamic import() for lazy loading — React + editor code only loaded when component renders
  • Model reset: changing initialModel reference after init re-mounts the full React root

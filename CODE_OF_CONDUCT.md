# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1 as its Code of Conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

If you experience or witness unacceptable behavior, please open a [confidential GitHub issue](https://github.com/ag-gr-hub/flowchart-sequence-designer-angular/issues/new) or contact the maintainers directly via the email listed on the [GitHub profile](https://github.com/ag-gr-hub).

Reports will be reviewed and investigated promptly and fairly. All maintainers are obligated to respect the privacy and security of the reporter.
